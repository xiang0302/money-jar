# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-08-21

### Added
- Initial release of Money Jar accounting app
- Multi-currency support (MYR, CNY, USD, SGD, EUR, HKD, JPY)
- Asset jar management with initial balance and monthly savings goals
- Budget jar management with spending limits
- Transaction recording with date and notes
- Fund transfer between jars
- Spending analysis and breakdown by jar
- Daily/monthly spending trends visualization
- Investment tracking with revaluation support
- Data backup/restore functionality
- Live exchange rate fetching
- Print and PDF export capabilities
- Responsive mobile-friendly design
- Local storage data persistence

### Technical
- Single-page HTML application
- Pure JavaScript (no frameworks)
- Canvas-based charting
- Local browser storage for data privacy
